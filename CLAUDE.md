# CLAUDE.md

Context for agent runs. Generated by inspecting the repository, pruned by hand,
and committed — so what shapes agent behaviour is reviewable in a diff.

Every line here is re-read on every run. Keep it short. If something is true but
never changes what an agent does, delete it.

## What this is

A FastAPI demo application. It exists to prove a delivery pipeline, not to be a
product. Small and boring is correct.

## Commands

```
uv sync --locked      # install; --locked fails on a stale lockfile, never use --frozen
uv run pytest -q      # tests
uv run ruff check     # lint
uv run ruff format    # format
```

Run all four before finishing. CI runs the same commands and a Docker build that
must boot and answer `GET /health`.

## Layout

- `app/main.py` — the FastAPI app. Currently `GET /` and `GET /health`.
- `tests/` — `unittest` classes driven by pytest, using `fastapi.testclient`.
  Match the existing style rather than introducing bare pytest functions.
- Dependencies live in `pyproject.toml`, locked in `uv.lock`.

## Conventions

- Python 3.13. Ruff defaults; no separate formatter.
- Tests name the behaviour they pin: `test_get_note_missing_id_returns_404`,
  not `test_notes_2`.
- Do not add dependencies. Both FastAPI and Pydantic are already available.

## Paths you cannot change

`.github/`, `CLAUDE.md`, `.claude/`, `Dockerfile`, `.dockerignore`, and any
scanner configuration are the privilege surface. A check rejects a pull request
from a non-human author that touches them, so editing one fails the run rather
than merging. This file is in that list on purpose: an agent that can rewrite
its own instructions rewrites every future run.

If a task appears to require one of these paths, stop and say so in the pull
request instead of working around it.

## How work arrives

A tracked issue states an outcome, machine-checkable acceptance criteria, the
tests to write, and a file scope. Implement what it specifies — nothing
adjacent, however tempting. If a criterion is ambiguous, implement the reading
that the named test would prove, and say which reading you took.
